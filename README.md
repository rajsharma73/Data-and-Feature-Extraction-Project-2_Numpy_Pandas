#  Feature & Data Extraction from CSV (194 Countries)

## 📌 Project Overview
This project focuses on **feature extraction and data analysis** from a CSV file containing data of **194 countries** with multiple attributes (columns). Using **Python**, **Pandas**, and **NumPy**, the project demonstrates how to load, clean, analyze, and extract meaningful insights from real-world tabular data.

The goal of this project is to build a strong foundation in **data handling, preprocessing, and exploratory data analysis (EDA)**, which are essential skills for **Data Science, Machine Learning, and Analytics**.

---

## 🛠️ Technologies Used
- **Python 3.x**
- **Pandas** – Data manipulation & analysis
- **NumPy** – Numerical operations
- **Jupyter Notebook / Python Script**

---

## 📂 Dataset Description
- **Format:** CSV file  
- **Records:** 194 countries  
- **Columns:** Multiple features such as demographic, economic, and regional attributes (depending on the dataset)

- Country Name  
- Population  
- Area  
- GDP  
- Literacy Rate  
- Region  
- Other numerical and categorical features
